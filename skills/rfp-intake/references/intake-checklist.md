# Intake checklist and output template

Use these criteria when the user has not supplied their own go/no-go
checklist. When they have, apply theirs first and use this list only to fill
gaps, and say which is which.

## Default go/no-go criteria

Score each as favorable, neutral, unfavorable, or unknown. "Unknown" is a
finding, not a gap to paper over: list what document or question would
resolve it.

| Area | What to look for |
|---|---|
| Owner and relationship | Public or private owner, prior history with this owner, who the architect or engineer of record is, whether a CM or program manager sits between the owner and the GC. |
| Delivery method and contract | Design-bid-build, design-build, CM at risk, CMa, IPD. Contract form (AIA, ConsensusDocs, owner-custom). Lump sum, GMP, cost-plus, unit price. |
| Schedule | Bid due date relative to today, construction start, substantial completion, liquidated damages amount and trigger, phasing or occupied-facility constraints. |
| Bonding and insurance | Bid bond percentage, performance and payment bond requirement, insurance limits and any unusual endorsements (builder's risk responsibility, pollution, professional liability). |
| Licensing and prequalification | State or municipal license class required, prequalification deadline and status, DBE/MBE/WBE/SBE participation goals, apprenticeship or local-hire requirements. |
| Wage and labor | Prevailing wage or Davis-Bacon, project labor agreement, union requirements, certified payroll obligations. |
| Scope fit | Building type, size, self-perform opportunity, trades that are hard to source locally, specialty systems. |
| Competition | Number of invited bidders if stated, public plan-holder list, whether a preferred contractor is evident from the documents. |
| Risk allocation | Differing site conditions clause, no-damages-for-delay, hazardous materials responsibility, permit responsibility, allowances and contingency treatment, retainage percentage and release terms. |
| Documents | Design completeness (percentage or phase), addenda issued so far, number of drawing sheets and spec divisions, geotechnical report present or absent. |

## Output template

Lead with the recommendation. Keep the whole review readable in one screen
before the detail sections.

```
# Intake review: <project name>

**Recommendation:** Go | No-go | Go with conditions
**Why in one line:** <the single most decisive factor>

## Key dates
| Milestone | Date | Source |
|---|---|---|
| Questions deadline | | <doc, page> |
| Pre-bid meeting / site visit | | |
| Addenda (last issued) | | |
| Bid due | | |
| Anticipated award | | |
| Construction start | | |
| Substantial completion | | |

## Project snapshot
Owner, location, delivery method, contract type, size, budget if stated. Cite each.

## Requirements to bid
Forms, bid bond, prequalification, licensing, participation goals, wage rules. Cite each.

## Scope summary
In the trades' own terms. Note self-perform candidates and hard-to-source trades.

## Risk flags
One bullet per risk: what the document says, page, and why it bites.

## Go/no-go scorecard
| Criterion | Rating | Note |
|---|---|---|

## Open questions
What to ask before the questions deadline.

## Sources
Which findings came from the user's documents, which came from the user's checklist, and what is still generic.
```
