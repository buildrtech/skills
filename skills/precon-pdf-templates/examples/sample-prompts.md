# Sample prompts

Prompts that should trigger this skill. Attach the source data (estimate
export, spreadsheet, bio, existing proposal) in each case.

- "Turn this budget export into a clean PDF for the owner meeting."
- "Make a design development milestone estimate PDF from this spreadsheet, with our inclusions and exclusions."
- "Generate a proposal for the Cedar Hollow library expansion using the attached scope, schedule, and pricing. Use a public-agency look."
- "Format an executive project health report for the steering committee from this week's status notes."
- "Build one-page resumes for these three superintendents for the RFQ team section. Bios and project lists attached."
- "Lay out this estimate as a bid book with a cover, commercial summary, and signature page."
- "Export the attached line items and markups to a PDF budget table that keeps division headers on every page."

Prompts that should not trigger this skill:

- "Estimate the cost of this project." (produces numbers; this skill only formats them)
- "Should we bid this RFP?" (intake and go/no-go, not document production)
- "Write the executive summary for our proposal." (copywriting; this skill lays out copy the user supplies)
